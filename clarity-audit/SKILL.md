# Clarity Audit — 文本模糊度审查器

> 检测文本中的"虚词"和"弱词"，让文字更有力量

## 🎯 解决什么问题

写出来的文字总是太虚、太绕、太软？
- "我觉得可能大概基本上..."
- "这个呢其实呢..."
- 重要信息被一堆废话淹没

**Clarity Audit** 快速定位问题词，给出具体改法。

---

## 📖 使用方法

### Step 1：输入待审查文本

```
帮我审核这段话：
[你的文本]
```

### Step 2：自动识别问题词

系统会标记以下问题：

| 问题类型 | 示例 | 问题 |
|----------|------|------|
| **填充词** | 实际上、基本上、大概、总的来说 | 占用篇幅，无信息增量 |
| **弱化词** | 我觉得、可能、应该、也许、大概 | 削弱观点力度 |
| **模糊词** | 一些、某些、相关、等等 | 缺乏具体性 |
| **废话结构** | 其实呢、然后呢、那么就是说 | 口语化拖沓 |
| **重复词** | 反复使用同一形容词/动词 | 用词单一 |

### Step 3：输出修改建议

```
━━━ Clarity Audit 结果 ━━━

❌ 问题词检测（3处）

1. "我觉得可能应该"
   → 位置：第2句
   → 问题：弱化词堆砌，削弱说服力
   → 改法：直接说结论，去掉"我觉得"

2. "基本上"
   → 位置：第3句
   → 问题：填充词，无实质信息
   → 改法：直接删掉，或换成具体事实

3. "等等"
   → 位置：第5句
   → 问题：模糊词，读者不知道具体是什么
   → 改法：列出具体项目

━━━ 干净版本 ━━━

[改后的清晰版本]

━━━ 清晰度评分 ━━━
原始：52/100 ████████░░░░░░░░░░░
改后：87/100 ███████████████░░░░

提升：+35 分
```
